🔍 ATF2029 게시글 조건 검색 매뉴얼

v1.0

📦 1. 확장프로그램 설치 방법

  1. Chrome 브라우저를 열고 주소창에 chrome://extensions 를 입력해 이동합니다.
  2. 우측 상단의 [개발자 모드] 토글 스위치를 켭니다.
  3. 좌측 상단에 나타나는 [압축해제된 확장 프로그램을 로드합니다] 버튼을 클릭합니다.
  4. 다운로드한 ATF2029 소스코드 폴더 전체를 선택합니다.
  5. 브런치 운영툴(brunch-admin.onkakao.net/article/daily)에 접속하면 자동으로 버튼이 추가됩니다.

🚀 2. 주요 기능 및 사용법

🗓️ 발행 시각 조건

24시간 이내 또는 직접 지정(최대 3일) 범위를 설정해 원천 데이터를 조회합니다.

🎯 포함/제외 조건

제목, 키워드, 매거진, 작가 조건(AND/OR 선택)과 유저타입(화이트/그레이/블랙/레드) + 멤버십 전문 조회 제외 필터를 조합할 수 있습니다.

📥 결과 엑셀 다운로드

검색된 결과를 .xlsx 파일로 다운로드합니다. 백그라운드에서 작가의 실제 브런치 주소(/@handle)를 변환해 링크로 저장합니다.

⚡ 즉시 운영 액션

검색 결과 표에서 체크박스 일괄 선택 또는 개별 버튼으로 PC 홈 추천, 피처링 추천, 블랙/레드글 등록 및 작가 등급 변경을 실행할 수 있습니다.

📊 3. 구글 시트 키워드 저장 연동

  • 포함 조건에서 키워드를 등록한 후 [저장] 버튼을 누르면 구글 시트 매핑 모달이 열립니다.
  • 각 키워드를 저장할 대상 시트(종교/홍보/노출 불가)를 지정한 후 저장할 수 있습니다.
  • 이미 시트에 존재하는 키워드는 중복으로 자동 제외되며, 신규 키워드만 Apps Script를 통해 추가됩니다.

💡 4. 작업 효율성을 높여주는 편의 기능

🔗 [글 정보] / [작가 정보] 새 탭 열기 (검색 상태 유지)
기존 운영툴과 달리 [글 정보] 및 [작가 정보] 링크를 클릭하면 새 탭(새 창)으로 열립니다. 따라서 수집된 검색 결과 테이블과 작업 상태가 사라지지 않고 그대로 유지되어 연속 작업이 편리합니다.
⚡ 동일 조건 5분 세션 캐싱 기법
동일한 기간 조건으로 페이지 이동 없이 반복 검색 시, 기존 메모리 캐시 데이터를 즉시 활용해 속도를 최적화합니다.
📊 결과 컬럼 클릭 정렬
조회수, 댓글수, 라이킷, 탑리스트 등의 컬럼 헤더를 클릭하여 오름차순/내림차순으로 결과를 즉시 정렬할 수 있습니다.
🛡️ 작가 그레이/블랙/레드리스트 등록 시 2단계 확인 절차
[작가 정보] 드롭다운에서 그레이/블랙/레드리스트를 등록할 때, 원본 운영툴에는 없는 확인 단계가 추가로 들어갑니다. 사유를 입력하면 곧바로 등록되는 것이 아니라, "작가 [ID]를 [등급]에 등록합니다. 사유: [입력한 내용] — 진행할까요?" 라는 최종 확인창이 한 번 더 뜨고, [확인]을 눌러야 실제로 등록됩니다. 작가 단위 제재는 글 단위보다 파급 범위가 훨씬 큰 만큼, 실수로 잘못된 작가나 등급을 등록하는 사고를 이 단계에서 막을 수 있습니다.

⚠️ 5. 주의사항 및 제약사항

⚠️ 운영 액션 실행 시 검색 결과 표 풀림 안내 (★ 중요):
검색 결과 화면에서 블랙글/레드글 등록, 작가 등급 변경을 실행하면, 브런치 운영툴 원본 화면이 그 부분을 자체적으로 다시 그리면서 그 위에 끼워둔 커스텀 검색 결과 표가 함께 사라집니다. (PC 홈 추천/피처링 추천은 이 현상이 없습니다 — 아래 별도 안내 참고)
(전체 페이지가 새로고침되는 것은 아니고, 원본이 자기 내부에 기억하고 있는 검색 조건 기준으로 목록 영역만 조용히 다시 렌더링하는 방식입니다. 원본 사이트 자체 검색으로 등록하면 결과가 유지되는 이유도, 그 조건이 사이트 내부 상태에 저장돼 있어 다시 그려도 그대로 유지되기 때문입니다. 확장 검색은 원본 검색창을 건드리지 않고 별도로 데이터를 가져와 표를 끼워넣는 구조라, 다시 그려질 때 그 조건이 반영되지 않습니다.)
등록 자체는 정상적으로 처리되며, 표가 풀린 뒤에는 팝업창에서 [검색] 버튼을 다시 눌러 최신 상태(방금 등록한 뱃지 포함)를 확인하시면 됩니다.
권장 사용 방식: 검색 후 한 건씩 처리하거나, 여러 건을 한 번에 처리해야 할 때는 같은 페이지 안에서 체크박스로 여러 건을 골라 한 번에 등록하는 방식을 권장합니다. (다른 페이지로 넘어갔다가 돌아오면 체크 표시가 유지되지 않으므로, 페이지를 이동하기 전에 그 페이지에서 필요한 처리를 먼저 마치는 것이 안전합니다.)
※ [작가 정보]의 그레이/블랙/레드리스트 등록은 체크박스 다중선택 자체를 지원하지 않습니다(글 단위 블랙/레드글 등록과 달리 작가 등급 변경은 항상 한 명씩 개별 처리해야 합니다).
✅ PC 홈 추천 / 피처링 추천은 검색 결과가 풀리지 않습니다
위 항목들과 달리 PC 홈 추천 / 피처링 추천은 몇 건을 처리하든(행별 단건, 체크박스 다중선택 모두) 검색 결과 표가 풀리지 않습니다. 등록 직후 그 글의 뱃지도 자동으로 갱신되므로, 다른 페이지로 이동했다가 돌아와도 방금 등록한 뱃지가 그대로 남아있습니다.
다만 체크박스 다중선택은 여전히 한 페이지 안에서만 유효합니다. 1페이지에서 몇 건을 체크한 뒤 2페이지로 넘어가 또 체크해서, 이 둘을 한 번의 클릭으로 합쳐서 처리하는 것은 불가능합니다(페이지를 넘기는 순간 이전 페이지의 체크박스는 화면에서 완전히 사라지는 구조라서, 원본 사이트가 인식할 수 있는 체크 대상 자체가 아니게 됩니다). 검색 결과가 풀리지 않으므로, 페이지마다 나눠서 체크→처리를 반복하시면 됩니다.
⚠️ 발행 시각 조건을 끌 경우:
발행 시각 체크를 해제하고 포함/제외 조건만으로 검색 시, 서버 부하 방지 및 속도를 위해 기본적으로 오늘 날짜(최근 1일) 기준으로만 검색됩니다. 더 오래된 글을 찾을 때는 반드시 [직접 지정]을 사용해 주세요.
🛑 대량 페이지 수집 시 경고:
조회 기간을 너무 넓게 설정하여 200페이지(약 3,000건 이상)를 초과할 경우 운영툴 서버 부하 방지를 위해 confirmation 경고 모달이 뜹니다. 가급적 날짜 범위를 좁혀서 검색하는 것을 권장합니다.
ℹ️ "오늘만무료 추천" 기능 종료 안내:
멤버십 글 목록에 표시되는 [오늘만무료 추천] 버튼은 2026년 7월 7일부로 서비스 기능이 종료되었습니다. UI 버튼만 남아있으며, 클릭 시 종료 안내 모달창이 표시됩니다.

🏷️ 6. 주요 뱃지 및 액션 버튼 안내

  • 블랙글 레드글 : 운영 기준에 따라 제한된 게시글 표기
  • 화이트유저 그레이유저 블랙유저 레드유저 : 작가 관리 상태 표기
  • 오늘만 무료 : 멤버십 프로모션 적용 글 표기
  • 응원 내역 조회 : 해당 글이 응원(후원) 허용 글인 경우 노출되며, 클릭 시 상세 내역 페이지로 이동
  • 멤버십 전문 조회 : 멤버십 글인 경우 노출되며, 클릭 시 작가 공개 주소로 전문 이동
  • 오늘만무료 추천 : 멤버십 콘텐츠 대상 행 액션 버튼 (※ 기능 서비스 종료됨)
