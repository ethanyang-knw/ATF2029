🔍 ATF2029 게시글 조건 검색 매뉴얼

v1.0

📦 1. 확장프로그램 설치 방법

  1. Chrome 브라우저를 열고 주소창에 chrome://extensions 를 입력해 이동합니다.
  2. 우측 상단의 [개발자 모드] 토글 스위치를 켭니다.
  3. 좌측 상단에 나타나는 [압축해제된 확장 프로그램을 로드합니다] 버튼을 클릭합니다.
  4. 다운로드한 ATF2029 소스코드 폴더 전체를 선택합니다.
  5. 브런치 운영툴(brunch-admin.onkakao.net/article/daily)에 접속하면 자동으로 버튼이 추가됩니다.

🚀 2. 주요 기능 및 사용법

🗓️ 발행 시각 조건

24시간 이내 또는 직접 지정(시작일로부터 최대 3일) 중 하나를 선택해 조회 범위를 지정합니다.

🎯 포함/제외 조건

포함 조건은 제목+키워드 / 제목 / 키워드 중 선택(여러 개 추가 시 AND/OR), 제외 조건은 화이트/그레이/블랙/레드유저 + 멤버십 전문 조회를 조합합니다. 검색창을 열면 제외 조건 5개가 기본으로 다 선택돼 있어요.

📥 결과 엑셀 다운로드

검색된 결과를 .xlsx 파일로 다운로드합니다. 작가의 실제 브런치 주소(/@handle)를 조회해 하이퍼링크로 저장합니다.

📊 검색 건수 안내

검색을 누르면 화면엔 "총 N건"처럼 건수만 안내됩니다. 제목·URL·작가명 같은 상세 내용은 화면에 표로 그려지지 않고, 다운로드한 엑셀 파일에서만 확인할 수 있습니다.

ℹ️ 운영 액션(등록·추천) 기능은 이 확장에 없습니다
블랙/레드글 등록, PC 홈/피처링 추천, 작가 정보(유저 타입) 등록 같은 운영 액션 기능은 처음부터 포함돼 있지 않습니다. 이 확장은 조건검색과 엑셀 다운로드만 담당하며, 등록·추천이 필요하면 원본 운영툴 화면에서 직접 진행해 주세요.

📊 3. 구글 시트 키워드 저장 연동

  • 포함 조건에서 키워드를 등록한 후 [저장] 버튼을 누르면 구글 시트 매핑 모달이 열립니다.
  • 각 키워드를 저장할 대상 시트(종교/홍보/노출 불가)를 지정한 후 저장할 수 있습니다.
  • 이미 시트에 존재하는 키워드는 중복으로 자동 제외되며, 신규 키워드만 Apps Script를 통해 추가됩니다.

💡 4. 작업 효율성을 높여주는 편의 기능

⚡ 동일 조건 5분 캐싱
같은 조건으로 5분 안에 다시 검색하면 서버 재조회 없이 기존 결과를 즉시 재사용합니다. 그사이 새로 올라온 글까지 확인하고 싶다면 [캐시 무시하고 재검색] 체크박스를 켜고 검색하세요(서버에서 새로 조회하므로 느려집니다).
🔁 작가 실제 주소 캐싱(30일)
다운로드 시 조회한 작가의 실제 브런치 주소는 30일간 저장돼, 같은 작가가 다시 나오면 재조회 없이 바로 재사용합니다. 고유 작가 수가 많은 검색을 반복해도 두 번째부터는 훨씬 빨라집니다.
🗂️ 오류 로그 자동 저장
검색 중 오류가 발생하면 자동으로 .txt 로그 파일이 저장됩니다(정상적으로 끝난 검색은 파일을 남기지 않습니다). 오류가 없어도 상단 [로그 저장] 버튼으로 언제든 수동 저장할 수 있습니다.

⚠️ 5. 주의사항 및 제약사항

⚠️ 검색 중에는 원본 운영툴 페이지를 이동하지 마세요 (★ 중요):
검색이 진행되는 동안 브런치 운영툴 페이지(탭)를 다른 화면으로 이동하거나 새로고침하면, 진행 중이던 검색이 그대로 중단되고 확장 상태가 초기화됩니다. 검색·다운로드가 끝날 때까지 페이지 이동은 피해 주세요.
⚠️ "직접 지정" 검색은 최대 3일까지:
발행 시각을 [직접 지정]으로 설정할 때는 시작일로부터 최대 3일 범위까지만 조회할 수 있습니다. 발행 시각 조건 자체를 끄는 기능은 없습니다(항상 24시간 이내 또는 직접 지정 중 하나가 적용됩니다).
🛑 대량 페이지 수집 시 경고:
조회 기간을 너무 넓게 설정하여 200페이지를 초과할 경우 운영툴 서버 부하 방지를 위해 확인 모달이 뜹니다. 가급적 날짜 범위를 좁혀서 검색하는 것을 권장합니다.
⚠️ 검색·다운로드가 이미 진행 중일 때 다시 누르면:
검색 또는 다운로드가 아직 끝나지 않은 상태에서 같은 버튼을 다시 누르면 새로 시작되지 않고 "이미 진행 중입니다"라는 안내가 뜹니다. 기존 작업이 끝날 때까지 기다려 주세요.
