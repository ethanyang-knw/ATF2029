🔍 ATF2029 게시글 조건 검색 매뉴얼

v1.0

📦 1. 확장프로그램 설치 방법

  1. Chrome 브라우저를 열고 주소창에 chrome://extensions 를 입력해 이동합니다.
  2. 우측 상단의 [개발자 모드] 토글 스위치를 켭니다.
  3. 좌측 상단에 나타나는 [압축해제된 확장 프로그램을 로드합니다] 버튼을 클릭합니다.
  4. 다운로드한 ATF2029 소스코드 폴더 전체를 선택합니다.
  5. 브런치 운영툴(brunch-admin.onkakao.net/article/daily)에 접속하면 자동으로 버튼이 추가됩니다.

🚀 2. 주요 기능 및 사용법

🗓️ 발행 시각 조건

24시간 이내 또는 직접 지정(최대 3일) 범위를 설정해 원천 데이터를 조회합니다.

🎯 포함/제외 조건

제목, 키워드, 매거진, 작가 조건(AND/OR 선택)과 유저타입(화이트/그레이/블랙/레드) + 멤버십 전문 조회 제외 필터를 조합할 수 있습니다.

📥 결과 엑셀 다운로드

검색된 결과를 .xlsx 파일로 다운로드합니다. 백그라운드에서 작가의 실제 브런치 주소(/@handle)를 변환해 링크로 저장합니다.

🏷️ 뱃지 표시

블랙글/레드글, 유저타입(화이트/그레이/블랙/레드), 오늘만무료, PC홈/탑추천 등 원본 사이트에 이미 등록된 상태를 검색 결과에 그대로 표시합니다.

⚠️ 운영 액션은 현재 비활성화 상태입니다
블랙/레드글 등록, PC 홈/피처링 추천, 작가 정보(화이트/그레이/블랙/레드리스트) 등록 버튼·링크·체크박스는 화면에 그대로 보이지만, 클릭해도 실제로 등록·추천이 일어나지 않습니다. 자세한 내용은 아래 5번 항목을 참고하세요.

📊 3. 구글 시트 키워드 저장 연동

  • 포함 조건에서 키워드를 등록한 후 [저장] 버튼을 누르면 구글 시트 매핑 모달이 열립니다.
  • 각 키워드를 저장할 대상 시트(종교/홍보/노출 불가)를 지정한 후 저장할 수 있습니다.
  • 이미 시트에 존재하는 키워드는 중복으로 자동 제외되며, 신규 키워드만 Apps Script를 통해 추가됩니다.

💡 4. 작업 효율성을 높여주는 편의 기능

🖼️ 검색 결과 화면은 원본 운영툴의 UI를 그대로 반영합니다
검색 결과 표는 브런치 운영툴의 발행글 리스트 화면(원본 테이블)을 그대로 복제해서, 실제 검색된 데이터만 채워 넣는 방식으로 만들어집니다. 그래서 컬럼 구성, 뱃지 모양, 버튼 스타일 등이 원본 운영툴 화면과 동일하게 보입니다.
🔗 [글 정보] / [작가 정보] 새 탭 열기 (검색 상태 유지)
기존 운영툴과 달리 [글 정보] 및 [작가 정보] 링크를 클릭하면 새 탭(새 창)으로 열립니다. 따라서 수집된 검색 결과 테이블과 작업 상태가 사라지지 않고 그대로 유지되어 연속 작업이 편리합니다.
⚡ 동일 조건 5분 세션 캐싱 기법
동일한 기간 조건으로 페이지 이동 없이 반복 검색 시, 기존 메모리 캐시 데이터를 즉시 활용해 속도를 최적화합니다.

⚠️ 5. 주의사항 및 제약사항

⚠️ 블랙/레드글 등록, PC 홈/피처링 추천, 작가 정보 등록은 현재 비활성화 상태입니다 (★ 중요):
검색 결과 화면의 블랙글/레드글 등록, 작가 등급 변경, PC 홈/피처링 추천 버튼·링크·드롭다운·체크박스는 화면에 그대로 보이지만, 클릭하거나 체크해도 실제로 아무 동작도 일어나지 않습니다. 원본 사이트에 이미 등록되어 있는 상태(뱃지)는 검색 결과에 그대로 표시되지만, 이 화면에서 새로 등록하거나 변경할 수는 없습니다.
실제로 등록하거나 추천을 걸어야 하는 경우에는 원본 운영툴 화면에서 직접 진행해 주세요.
⚠️ 발행 시각 조건을 끌 경우:
발행 시각 체크를 해제하고 포함/제외 조건만으로 검색 시, 서버 부하 방지 및 속도를 위해 기본적으로 오늘 날짜(최근 1일) 기준으로만 검색됩니다. 더 오래된 글을 찾을 때는 반드시 [직접 지정]을 사용해 주세요.
🛑 대량 페이지 수집 시 경고:
조회 기간을 너무 넓게 설정하여 200페이지(약 3,000건 이상)를 초과할 경우 운영툴 서버 부하 방지를 위해 confirmation 경고 모달이 뜹니다. 가급적 날짜 범위를 좁혀서 검색하는 것을 권장합니다.
