# ATF2029 게시글 조건 검색

브런치 운영툴(`brunch-admin.onkakao.net`)의 발행글 리스트 화면에 **조건 검색 + 엑셀 다운로드** 기능을 추가하는 크롬 확장프로그램입니다.

원본 운영툴은 기본적으로 "발행 시각 24시간 이내" 게시물만 보여주는 제한이 있어, 그보다 오래되거나 특정 조건(키워드/유저 타입 등)으로 게시글을 찾아보기가 어렵습니다. 이 확장프로그램은 원하는 발행 기간과 포함/제외 조건으로 게시글을 검색하고, 결과를 `.xlsx` 파일로 다운로드할 수 있게 해줍니다.

> ⚠️ 검색 결과는 화면에 표로 그려주지 않습니다. 검색하면 "총 N건"처럼 건수만 안내하고, 실제 제목/URL/작가명 등 상세 내용은 다운로드한 엑셀 파일에서만 확인할 수 있습니다.

## 주요 기능

- **조건 검색**: 발행 시각(24시간 이내 / 직접 지정, 시작일로부터 최대 3일) + 포함 조건(제목+키워드 / 제목 / 키워드, 여러 개 추가 시 AND/OR 선택) + 제외 조건(화이트/그레이/블랙/레드유저, 멤버십 전문 조회 — 검색창을 열면 5개 다 기본 선택된 상태)을 조합해 검색
- **규제 키워드 자동 포함**: "규제 키워드 자동 포함" 체크박스(기본 ON)를 켜두면 구글 시트(종교/홍보/노출 불가 키워드)에 등록된 키워드가 제목/키워드에 포함된 게시글도 자동으로 검색결과에 포함(화면엔 목록을 표시하지 않고 내부적으로만 적용, 운영자가 직접 입력한 포함 조건과는 OR로 결합)
- **검색 결과 다운로드**: `.xlsx` 파일로 다운로드(제목/URL/작가명, URL은 하이퍼링크 포함) — 외부 라이브러리 없이 순수 JS로 직접 생성
- **키워드를 구글 시트에 저장**: 포함 조건에 입력한 키워드를 종교/홍보/노출 불가 키워드 시트 중 골라서 저장 가능(중복 자동 제외)
- **오류 로그 자동 저장**: 검색 중 오류가 발생하면 자동으로 `.txt` 파일로 저장(깨끗한 검색은 파일을 남기지 않음). 오류가 없어도 상단 "로그 저장" 버튼으로 수동 저장 가능
- **5분 캐시**: 같은 조건으로 5분 안에 다시 검색하면 서버 재조회 없이 즉시 결과 반환(강제로 새로 조회하려면 "캐시 무시하고 재검색" 체크)

## 설치 방법

1. 이 저장소를 다운로드하거나 clone합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력해 확장프로그램 관리 페이지로 이동합니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 눌러, 이 저장소 폴더를 선택합니다.
5. `brunch-admin.onkakao.net`의 발행글 리스트 페이지(`/article/daily`)에 접속하면 자동으로 적용됩니다.

> 코드를 수정한 뒤에는 `manifest.json`의 `version`도 함께 올려주세요. 크롬 확장 관리 페이지에서
> 새로고침(🔄)을 눌러도 버전 표시는 그대로라, 지금 깔려있는 게 어떤 버전인지 나중에 헷갈릴 수 있습니다.

## 사용법

1. 발행글 리스트 페이지에서 확장프로그램이 추가한 [🔍 조건검색] 버튼을 눌러 검색 팝업을 엽니다.
2. **발행 시각**, **포함 조건**, **제외 조건**을 원하는 대로 설정합니다. ("규제 키워드 자동 포함"은 기본 켜짐 상태입니다.)
3. **검색** 버튼을 누르면 조건에 맞는 게시글 건수가 안내됩니다.
4. **다운로드** 버튼으로 검색 결과를 `.xlsx` 파일로 받습니다. 상세 내용은 이 파일에서 확인합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장프로그램 설정(권한, 로드할 스크립트 등) |
| `console-log.js` | 콘솔 로그를 모아뒀다가 오류 발생 시 `.txt`로 자동 저장 |
| `xlsx-writer.js` | 검색 결과를 `.xlsx` 파일로 만드는 유틸(ZIP+OOXML 직접 구현), `window.ATF_buildXlsxBlob()` 하나만 노출 |
| `content-main.js` | 발행글 목록 수집·필터링, 검색 팝업(iframe) 생성, 검색 실행·다운로드, 작가 실제 주소 조회, 초기화 진입점 |
| `popup.html` / `popup.css` / `popup.js` | 검색 조건 입력 팝업 UI |
| `Code.gs` | 구글 시트 연동용 Apps Script(키워드 조회/저장). 확장 코드와 별도로 Google Apps Script 프로젝트에 배포해서 사용 |

## 권한

- `storage`: 검색 조건 등 로컬 저장용
- `host_permissions`: `brunch-admin.onkakao.net`(운영툴 — 게시글 조회·작가 실제 주소 조회 모두 같은 도메인), `script.google.com`/`script.googleusercontent.com`(구글시트 연동)

## 알려진 제한사항

- "직접 지정" 검색은 시작일로부터 최대 3일까지만 가능합니다.
- 발행시각 범위가 넓거나 고유 작가 수가 많으면 다운로드(작가 실제 주소 조회) 시간이 오래 걸릴 수 있습니다(같은 작가는 30일간 캐시되어 재조회 시 빨라집니다).
- 검색 중 원본 운영툴 페이지를 다른 페이지로 이동하면 검색이 중단되고 확장 상태가 초기화됩니다. 검색이 끝날 때까지 페이지 이동은 피해 주세요.
