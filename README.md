# ATF2029 게시글 조건 검색

브런치 운영툴(`brunch-admin.onkakao.net`)의 발행글 리스트 화면에 **조건 검색 기능**을 추가하는 크롬 확장프로그램입니다.

원본 운영툴은 기본적으로 "발행 시각 24시간 이내" 게시물만 보여주는 제한이 있어, 그보다 오래되거나 특정 조건(키워드/작가/유저 타입 등)으로 게시글을 찾아보기가 어려웠습니다. 이 확장프로그램은 원하는 발행 기간과 포함/제외 조건으로 게시글을 검색하고, 검색 결과를 표로 보여주며 `.xlsx` 파일로 다운로드할 수 있게 해줍니다.

> ⚠️ 블랙/레드글 등록, PC 홈/피처링 추천, 작가 정보(화이트/그레이/블랙/레드리스트) 등록 같은
> **운영 액션은 현재 비활성화되어 있습니다.** 관련 버튼·링크·체크박스는 화면에 그대로 보이지만
> 클릭해도 아무 동작이 일어나지 않습니다. 원본 사이트에 이미 등록되어 있던 뱃지(블랙글/레드글/
> 유저타입 등)는 검색 결과에 그대로 표시됩니다.

## 주요 기능

- **조건 검색**: 발행 시각(24시간 이내 / 직접 지정, 최대 3일) + 포함 조건(제목/키워드/매거진/작가 등, AND/OR 선택) + 제외 조건(유저 타입)을 조합해 검색
- **검색 결과 다운로드**: `.xlsx` 파일로 다운로드 (제목/URL/작가명 등, 하이퍼링크 포함) — 외부 라이브러리 없이 순수 JS로 직접 생성
- **뱃지 표시**: 블랙글/레드글, 유저타입(화이트/그레이/블랙/레드), 오늘만무료, PC홈/탑추천 등 원본 사이트에 이미 등록되어 있는 상태를 검색 결과에 그대로 표시
- **오류 로그 자동 저장**: 검색 중 오류가 발생하면 자동으로 `.txt` 파일로 저장 (깨끗한 검색은 파일을 남기지 않음). 오류가 없어도 원하면 상단 "로그 저장" 버튼으로 수동 저장 가능

## 설치 방법

1. 이 저장소를 다운로드하거나 clone합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력해 확장프로그램 관리 페이지로 이동합니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 눌러, 이 저장소 폴더를 선택합니다.
5. `brunch-admin.onkakao.net`의 발행글 리스트 페이지(`/article/daily`)에 접속하면 자동으로 적용됩니다.

> 코드를 수정한 뒤에는 `manifest.json`의 `version`도 함께 올려주세요. 크롬 확장 관리 페이지에서
> 새로고침(🔄)을 눌러도 버전 표시는 그대로라, 지금 깔려있는 게 어떤 버전인지 나중에 헷갈릴 수 있습니다.

## 사용법

1. 발행글 리스트 페이지에서 확장프로그램이 추가한 검색 아이콘을 눌러 검색 팝업을 엽니다.
2. **발행 시각**, **포함 조건**, **제외 조건**을 원하는 대로 설정합니다. 각 조건 왼쪽 체크박스를 해제하면 해당 조건은 검색에서 제외됩니다.
   - 발행 시각을 해제하면 포함/제외 조건만으로 검색하며, 이 경우 기본적으로 오늘 날짜 기준으로만 조회됩니다.
3. **검색** 버튼을 누르면 조건에 맞는 게시글이 표로 나타납니다.
4. 검색 결과 표에서 체크박스로 여러 건을 선택할 수 있고, 원본 사이트에 이미 등록된 뱃지도 함께 확인할 수 있습니다. (블랙/레드글 등록 등 행별 버튼·드롭다운은 현재 비활성화 상태입니다)
5. **다운로드** 버튼으로 검색 결과를 `.xlsx` 파일로 받을 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장프로그램 설정 (권한, 로드할 스크립트 등) |
| `background.js` | 서비스워커. 브런치 공개 주소(vanity handle) 조회용 |
| `console-log.js` | 콘솔 로그를 모아뒀다가 오류 발생 시 `.txt`로 자동 저장 (격리 world/메인 world 양쪽에서 로드) |
| `xlsx-writer.js` | 검색 결과를 `.xlsx` 파일로 만드는 유틸(ZIP+OOXML 직접 구현), `window.ATF_buildXlsxBlob()` 하나만 노출 |
| `content-badges.js` | 검색결과 뱃지 렌더링 + 행별 PC홈/피처링/오늘만무료 버튼 UI 생성 (예전 이름 content-actions.js) |
| `content-main.js` | 격리 world 전역 상태, 검색 팝업/모달 생성, 검색 실행·결과 렌더링·다운로드, 커스텀 alert/confirm/prompt 모달, 초기화 진입점 (예전엔 content-globals.js/content-bootstrap.js로 나뉘어 있었으나 병합됨) |
| `injected.js` | 발행글 목록 페이지 수집 (메인 world에서 실행) |
| `popup.html` / `popup.css` / `popup.js` | 검색 조건 입력 팝업 UI |

## 권한

- `storage`: 검색 조건 등 로컬 저장용
- `host_permissions`: `brunch-admin.onkakao.net`(운영툴), `script.google.com`/`script.googleusercontent.com`(구글시트 연동), `brunch.co.kr`(공개 주소 조회용)

## 알려진 제한사항

- 발행 시각 조건을 끄면 기본 조회 범위가 1일(오늘)로 제한됩니다. 더 넓은 기간을 원하면 "직접 지정"(최대 3일)을 사용하세요.
- 포함 조건에 키워드를 여러 개 추가하면, 옆의 **OR/AND 선택**으로 "하나만 맞아도 되는지" 또는 "전부 맞아야 하는지"를 고를 수 있습니다(기본값 OR).
- 블랙/레드글 등록, PC 홈/피처링 추천, 작가 정보(화이트/그레이/블랙/레드리스트) 등록은 현재 비활성화되어 있습니다. 관련 UI(버튼/링크/체크박스)는 그대로 보이지만 클릭해도 동작하지 않으며, 뱃지는 원본 사이트에 이미 등록된 상태만 표시합니다.
- "오늘만무료 추천" 버튼은 UI만 남아있으며, 클릭해도 아무 동작이 없습니다(예전엔 종료 안내가 떴으나 그 안내도 함께 비활성화됨).
- 브런치 공개 주소 + 글 번호로 특정 게시글 하나를 바로 찾는 기능은 원본 운영툴에 이미 있어 별도로 구현하지 않았습니다.
